# Pingviny — інструкції для Claude

Над цим проєктом працюють **двоє людей**, у кожного свій Claude (Claude Code).
Код синхронізується через GitHub: https://github.com/Gamarjomber/Pingviny

## Мова
- Спілкуйся українською.
- Коментарі в коді та повідомлення комітів — українською (короткі, по суті).

## Робота з Git (обов'язково)
1. **Перед початком роботи** завжди виконуй `git pull` на `main`, щоб отримати зміни друга.
2. **Ніколи не працюй напряму в `main`.** Для кожної задачі створюй гілку:
   `feature/<коротка-назва>` (нова функція) або `fix/<коротка-назва>` (виправлення).
3. Коміть невеликими логічними частинами.
4. Коли задача готова — запуш гілку і створи Pull Request у `main`.
   Не зливай PR сам, якщо користувач прямо не попросив.
5. Ніколи не роби `git push --force` у `main` і не переписуй чужі коміти.
6. Якщо при `pull` або злитті виникли конфлікти — покажи їх користувачу
   й поясни, що змінив кожен, перш ніж вирішувати.

## Хто що робить
Перед новою задачею переглянь `TASKS.md`: там записано, хто над чим працює.
Не чіпай файли, які зараз у роботі в іншої людини, без потреби.
Коли береш задачу — додай її в `TASKS.md` зі своїм ім'ям.

## Про проєкт
Тип проєкту та стек ще не визначені.
Коли їх буде обрано — онови цей розділ: стек, як запускати, структура папок, стиль коду.

## Безпека
- Не комітити паролі, токени, ключі API. Секрети — лише у `.env` (він у `.gitignore`).
