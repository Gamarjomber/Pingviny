# Pingviny 🐧

Спільний проєкт двох авторів.

## Як почати (для кожного учасника)

1. Встановити [Git](https://git-scm.com/) і Claude (десктоп-додаток, вкладка Code).
2. Склонувати репозиторій:
   ```
   git clone https://github.com/Gamarjomber/Pingviny.git
   ```
3. Відкрити папку `Pingviny` у Claude. Claude автоматично прочитає `CLAUDE.md` з правилами роботи.

## Як працюємо

- `main` — завжди робоча версія.
- Кожна задача — окрема гілка (`feature/...`, `fix/...`) → Pull Request → злиття в `main`.
- Перед роботою — `git pull`. Хто що робить — у `TASKS.md`.
